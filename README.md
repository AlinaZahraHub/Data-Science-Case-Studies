## 📁 Repository Structure

### 1. Titanic Case Study
* **Objective:** Perform comprehensive Exploratory Data Analysis (EDA) on the classic Titanic passenger dataset to uncover survival patterns, handle missing data, and analyze feature correlations.
* **Key Tasks Covered:**
  * Dataset inspection, shape evaluation, and data type verification.
  * Missing value analysis (handling missing ages via median and cleaning categorical features using mode).
  * Duplicate record checking.
  * Statistical summaries, extreme value detection, and boxplot outlier analysis.
  * Group-level survival comparisons based on gender and passenger class (`Pclass`).
  * Data visualizations including histograms, correlation heatmaps, and Seaborn bar plots.
* **Tools & Libraries Used:** Python, Pandas, NumPy, Matplotlib, Seaborn.
* **Jupyter Notebook:** [View Notebook](./Titanic%20Case%20Study/titanic.ipynb)
